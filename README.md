# dotfiles

## 使い方

```
git clone git@github.com:kyrieleison/dotfiles.git $HOME/.config
```

## 構成

- シェル zsh
    - フレームワーク [Zim](https://github.com/zimfw/zimfw)
- エディタ nvim
    - パッケージ管理 [vim-jetpack](https://github.com/tani/vim-jetpack)
    - ステータスライン [vim-airline](https://github.com/vim-airline/vim-airline)
    - ファイラー [Fern](https://github.com/lambdalisue/vim-fern)
    - カラースキーマ [Nord](https://www.nordtheme.com/docs/ports/vim/installation)
    - ファジーファインダー [fzf.vim](https://github.com/junegunn/fzf.vim)
    - バッファエクスプローラ [bufexplorer](https://github.com/jlanzarotta/bufexplorer)
- IDE Visual Studio Code
- ターミナルマルチプレクサ tmux
    - パッケージ管理 [tpm](https://github.com/tmux-plugins/tpm)
    - カラースキーマ [Nord](https://www.nordtheme.com/docs/ports/tmux/installation)
- ターミナルエミュレータ [Alacritty](https://github.com/alacritty/alacritty)
    - フォント [Cica](https://github.com/miiton/Cica)
    - カラースキーマ [Nord](https://github.com/nordtheme/iterm2)
- パッケージ管理 Homebrew
    - Brewfile管理 [homebrew-file](https://github.com/rcmdnk/homebrew-file)
- 言語バージョン管理 [mise](https://github.com/jdx/mise)
- ファイル検索 ripgrep
- ファジーファインダー fzf
